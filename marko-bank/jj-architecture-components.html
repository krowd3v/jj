JJ as reusable software components

A top-down reading of the Jujutsu source tree, mapped through the Marko groups in .marks.toml and the extracted banks in marko-bank/. The page shows the standalone modules, the flow between them, and the documentation surfaces worth making explicit.

Architectural Stack

JJ splits user interaction from repository mechanics. The CLI crate owns terminal behavior, argument parsing, configuration, command dispatch, and presentation. The library crate owns the storage-independent model: repositories, operations, indexes, revsets, working copies, and Git interoperability.

Flow Through The Components

These flows build upward from standalone modules into complete JJ behavior. Each step is anchored by a Marko tag and can be pulled from source with marko pull --group <group>.

Command execution
  1. Entrymain() creates CliRunner.
  2. BootstrapCliRunner::init() installs config, factories, extensions, and default dispatch.
  3. Runtimerun_internal() loads config, expands aliases, parses args, and creates CommandHelper.
  4. Dispatchrun_command() routes to the command implementation.
Workspace snapshot
  1. Prepareworkspace_helper_with_stats() loads workspace and repo context.
  2. Lockmaybe_snapshot_impl() takes the Git import/export lock when needed.
  3. Freshnesshandle_stale_working_copy() compares working-copy operation state with repo view state.
  4. PersistLockedLocalWorkingCopy::snapshot() writes the new tree state.
Repo transaction
  1. LoadRepoLoader::init_from_file_system() creates stores from repo paths and factories.
  2. MutateMutableRepo owns mutable view, index, predecessor, and rewrite state.
  3. Build commitsnew_commit() and rewrite_commit() return attached builders.
  4. Commit opTransaction::write() writes view, operation, and index, then publishes through commit().
Revset query
  1. Parserevset::parse() parses syntax, expands aliases, and lowers expressions.
  2. Bindresolve_symbols() maps names to commits, bookmarks, tags, and refs.
  3. Scoperesolve_visibility() inserts visible heads, root, and visibility bounds.
  4. Optimizeoptimize() folds, flattens, and rewrites the expression before evaluation.
Git interop
  1. Object adapterGitBackend implements JJ's commit backend over Git objects.
  2. Import HEADimport_head() reconciles Git HEAD with JJ view state.
  3. Import refsimport_refs() brings Git refs into JJ bookmarks and tags.
  4. Export refsexport_refs() writes selected JJ view updates back to Git refs.

Reusable Module Bank

These modules are cohesive enough to document, test, and reuse as standalone architectural parts. The last column names the surface where the documentation should live.

Module Standalone contract Primary source Doc surface
CliRunner Configurable CLI bootstrap with extension hooks and async dispatch. cli/src/cli_util.rs CLI embedding and command lifecycle.
CommandHelper Command context boundary for cwd, args, settings, config, and workspace loading. cli/src/cli_util.rs Command authoring guide.
WorkspaceCommandHelper Workspace/repo preparation with snapshot, Git import, and working-copy update policy. cli/src/cli_util.rs Working-copy lifecycle internals.
RepoLoader Storage-independent loader over store factories and repo path layout. lib/src/repo.rs Backend and repository loading API.
MutableRepo In-memory mutation model for view, index, commit predecessors, and rewrites. lib/src/repo.rs Repository mutation model.
Transaction Operation metadata, view persistence, index persistence, and op-head publication. lib/src/transaction.rs Operation log write path.
revset::parse and optimize DSL front end and transformation pipeline for commit-set queries. lib/src/revset.rs Revset implementation guide.
LocalWorkingCopy Stateful filesystem mutation with locking, snapshot, checkout, and finish phases. lib/src/local_working_copy.rs Working-copy backend contract.
git::import_refs and export_refs External reference synchronization between JJ view state and Git refs. lib/src/git.rs Git compatibility internals.
